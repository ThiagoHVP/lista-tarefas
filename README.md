# Lista de Tarefas

Aplicação web de lista de tarefas desenvolvida como projeto front-end.

O projeto permite adicionar, concluir e excluir tarefas, além de oferecer modo escuro, acessibilidade, navegação por teclado e layout responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- Git
- GitHub
- Vercel

## Funcionalidades

- Adicionar tarefas
- Concluir tarefas
- Desmarcar tarefas concluídas
- Excluir tarefas
- Contador de tarefas
- Modo claro e modo escuro
- Navegação por teclado
- Interface responsiva
- HTML semântico
- Recursos de acessibilidade

## Acessibilidade

O projeto utiliza recursos para facilitar o acesso e a navegação, incluindo:

- HTML semântico
- Labels associados aos campos
- Atributos ARIA quando necessários
- Indicador visual de foco
- Navegação por teclado
- Contraste adequado entre texto e fundo
- Botões com áreas de interação adequadas
